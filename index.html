XAge
Pediatric hand X-ray landmark detection. A deep-learning model that detects one hand and localizes 17 anatomical reference points to support standardized analysis for future automated bone-age estimation.

Model Notes

YOLO26s-Pose model trained on pediatric hand radiographs. It predicts one hand bounding box and 17 anatomical landmarks. The landmarks are not individual object classes and do not receive separate boxes.

Comparison · MediaPipe 3D Hand Pose

XAge analyzes pediatric hand X-rays and predicts a 2D hand box plus 17 custom radiographic landmarks. MediaPipe analyzes normal RGB hand images and predicts 21 general-purpose 3D hand landmarks. The systems have different input types, landmark definitions, and intended use cases.

XAge (this app)

Radiograph-based landmark detector for pediatric bone-age research.

  • Input: pediatric hand X-ray
  • Output: one hand box + 17 radiographic landmarks
  • Backbone: YOLO26s-Pose exported to ONNX
  • Runtime: ONNX Runtime Web
  • Use case: research-only anatomical standardization
MediaPipe Hands (3D)

Real-time RGB hand-pose regression for interaction applications.

  • Input: RGB webcam or normal hand photograph
  • Output: 21 three-dimensional hand points
  • Model: hand detector + landmark regressor
  • Runtime: TensorFlow.js / WebGL / WASM
  • Use case: gestures, AR, sign language, interaction
Open MediaPipe 3D Demo Read TF Blog Post

Note: MediaPipe uses 21 generic RGB-hand landmarks. XAge uses 17 custom radiographic landmarks from hand X-rays, so the two keypoint sets should not be interpreted as equivalent.

Research and educational use only. XAge is a research prototype for pediatric hand-radiograph landmark localization. It is not a certified medical device and must never be used for clinical diagnosis, treatment, or bone-age reporting.
