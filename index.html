Model Notes

YOLO26s-Pose detects exactly one hand and 17 anatomical landmarks per detected hand. The rectangle is one hand box only. The colored circles are landmarks, not separate boxes. There is no per-landmark class list — landmarks are numbered 1–17, not named object classes.

Comparison · MediaPipe 3D Hand Pose

XAge detects 17 custom 2D radiographic landmarks from pediatric hand X-rays. MediaPipe detects a different set of 21 general hand landmarks from RGB webcam images and estimates relative 3D pose. The systems have different inputs, landmark definitions, and uses.

XAge

Radiograph-based hand localization and landmark detection for bone-age research workflows.

  • Input: pediatric hand X-ray
  • Output: 1 hand box + 17 custom 2D landmarks
  • Runtime: ONNX Runtime Web
  • Use case: research-only anatomical standardization
MediaPipe Hands

Real-time RGB hand-pose estimation for gesture and interaction applications.

  • Input: RGB webcam or photograph
  • Output: 21 general hand points with relative depth
  • Runtime: TensorFlow.js / WebGL / WASM
  • Use case: AR, gestures, sign language, interaction
